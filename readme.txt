Add a customizable floating contact button to your WordPress site.

== Description ==

FloatConnect adds a customizable floating contact button to your WordPress website.

The Free version lets you display one contact method as a floating button.

Supported contact methods include WhatsApp, Phone, Email, Messenger, Telegram and Custom URL.

The button can be customized with different sizes, positioning, border radius, shadow and animation options.

A Premium version is also available with additional contact methods and advanced configuration options.

== Features ==

=== Free ===

* Single floating contact button.
* One configurable contact method.
* WhatsApp support.
* Phone support.
* Email support.
* Messenger support.
* Telegram support.
* Custom URL support.
* Bottom-left or bottom-right positioning.
* Configurable button size.
* Configurable icon size.
* Configurable button border radius.
* Configurable shadow.
* Optional pulse animation.
* Optional hover effect.
* Configurable bottom offset.
* Configurable side offset.
* Configurable z-index.
* Responsive frontend layout.
* Reduced-motion support.

== Contact Methods ==

FloatConnect supports the following contact types:

* WhatsApp
* Phone
* Email
* Messenger
* Telegram
* Custom URL

The Free version supports one contact at a time.

The configured contact is displayed through the floating Single button.

== Configuration ==

=== General ===

The Free version allows you to:

* Enable or disable the floating button.
* Select the button position.
* Configure the button appearance.
* Configure the button effects.
* Configure button spacing.
* Configure one contact method.

=== Appearance ===

The following appearance options are available:

* Button size.
* Icon size.
* Button border radius.
* Shadow style.

=== Effects ===

The following effects are available:

* No animation.
* Pulse animation.
* Bounce animation.
* Optional hover effect.

=== Position and spacing ===

The floating button position can be configured using:

* Bottom offset.
* Side offset.
* Z-index.

== Installation ==

1. Upload the `floatconnect` folder to the `/wp-content/plugins/` directory.
2. Activate FloatConnect through the `Plugins` menu in WordPress.
3. Open the FloatConnect settings page.
4. Enable the plugin.
5. Select a contact method.
6. Enter the contact value.
7. Configure the available appearance and positioning options.
8. Save your settings.

== Frequently Asked Questions ==

= Which contact methods are supported? =

FloatConnect supports WhatsApp, Phone, Email, Messenger, Telegram and Custom URLs.

= Can I display multiple contacts? =

The Free version supports one contact at a time.

Multiple contacts and additional configuration options are available in the Premium version.

= Can I display only one contact? =

Yes. The Free version is designed for one contact and one floating button.

= Can I choose where the button appears? =

Yes. The floating button can be positioned at the bottom-left or bottom-right of the screen.

= Can I change the button size? =

Yes. The button size and icon size can be configured independently.

= Can I change the button shape? =

Yes. The button border radius can be configured from 0% to 50%.

= Can I add an animation? =

Yes. The Free version supports Pulse and Bounce animations.

= Can I disable the hover effect? =

Yes. The hover effect can be enabled or disabled from the settings page.

= Does the plugin support reduced motion preferences? =

Yes. The frontend respects the user's `prefers-reduced-motion` preference.

= Does FloatConnect collect personal data? =

FloatConnect does not collect or transmit personal data to external services as part of its own contact button functionality.

Contact information entered in the plugin settings is stored in the WordPress database on the website where the plugin is installed.

= Does FloatConnect connect to external services? =

FloatConnect can generate links to external services such as WhatsApp, Messenger and Telegram.

These services are only contacted when a visitor follows a configured external link.

== Privacy ==

FloatConnect does not collect or transmit personal data to external services by itself.

Contact information entered in the plugin settings is stored as WordPress plugin settings on the website where the plugin is installed.

When visitors click a configured contact method, they may be redirected to an external service such as WhatsApp, Messenger or Telegram.

Any data processing performed by those external services is subject to the respective privacy policies of those services.

== External Services ==

FloatConnect can link visitors to third-party services when a corresponding contact method is configured.

The plugin may generate links to:

* WhatsApp
* Messenger
* Telegram
* Custom URLs configured by the website administrator

These services are only contacted when a visitor follows a configured external link.
